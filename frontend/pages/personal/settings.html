完整的 API 接口 URL，需包含路径（如 /v1/images/generations）

用于 Bearer 鉴权的密钥，将安全存储在服务端

如 dall-e-3、dall-e-2、stable-diffusion-xl 等

支持的 API 格式：OpenAI Images API（dall-e-3 等）、及任何兼容该格式的第三方服务。
